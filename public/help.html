🔐 AESBin

A self-hosted, single-user file manager that keeps everything it stores encrypted at rest, and runs on ordinary shared PHP hosting.

Encryption is server-side, not client-side. During an active session the server unwraps the master key for every request (the PHP session holds it only wrapped with a per-tab key), so this is not the same guarantee a zero-knowledge client-side app gives you.

What it defeats is theft of the database, the stored files, or the whole disk.

Read the threat model before deciding it fits your needs.
