# X-Robots-Tag header (pages, API, downloads, static files) and, on pages,
# <meta name="robots" content="noindex">. Both are only seen by a crawler

# elsewhere could then be listed as a bare URL. So crawling is allowed and
# indexing is refused response by response. (Read only at the root of a
# host: a subdirectory install relies on the headers and tags alone.)
